# Numberfactory / 质数工厂

Godot 4.7 / GDScript 二维数字自动化工厂。第一屏直接进入工厂，质数是原料，乘法是唯一合成规则。普通设备免费，没有限时失败、电力或维护费用。

## 本地网页试玩

本机已导出 `build/web/`，本地服务地址为 **http://127.0.0.1:8765/**。服务器只监听本机，不会将工程公开到网络。

重新导出并启动服务（本地服务脚本需要 Python 3）：

```powershell
.\tools\build_web.ps1
python .\tools\serve_web.py --port 8765
```

若端口被占用，换为 `--port 8766` 并访问对应地址。不要直接双击导出的 HTML；WebAssembly 和浏览器存档需要通过 HTTP/HTTPS 运行。

导出需要 Godot 4.7.2 及同版本官方 Web 模板。脚本优先使用本机 `.tools/portable/` 中的便携版，也支持 `-Godot 'C:\path\godot.exe'`。引擎、模板和构建目录不随源码提交。

已有便携版引擎、缺少模板时可运行 `tools/fetch_web_templates.ps1 -FullDownload`。该辅助脚本下载官方完整模板包，只提取 Web release 模板；下载约 1.2 GB。若使用普通 Godot 编辑器，请通过编辑器安装匹配模板。

## 部署

将 `build/web/` 的完整内容放入静态网站目录，保留所有相对文件名，包括 `.html`、`.js`、`.wasm`、`.pck`、图标和 `licenses/`。

正式部署使用 HTTPS，并使服务器以 `application/wasm` 提供 `.wasm`。当前预设使用 Compatibility 渲染、单线程、无 GDExtension、无 PWA，不要求多线程导出的跨源隔离头。参考 [Godot 官方 Web 导出文档](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_web.html)。

网页包没有外部运行时 API 或网络服务。服务器可以压缩传输，但不能丢失导出文件；不建议长时间缓存 `index.html`，更新游戏时应同时更新配套文件。

## 成长规则

- 世界按种子与 8×8 区块坐标确定性生成，支持负坐标，按需生成和可见区域绘制。离开镜头的已建产线仍生产。
- 初始开放居中 32×32 正方形，保证 2、3 矿点和研究站。每次支付开放整圈，四侧各增加 8 格：32 → 48 → 64 → 80。
- 引入 5、7、11、13 分别需要距上次质数研究额外扩张 3、5、8、12 次。之后间隔按 16、20……温和增加。达到门槛只开放研究，不自动解锁。
- 当前阶段的新质数有固定保障矿点，随机矿点也按坐标确定；提前探索不会替换旧矿点。未研究的矿点不出料。
- 产品真正进入研究站才增加研究库存与历史累计。扩张和研究扣库存，不清空累计；已开放研究产品持续接收。
- 费用按种子、阶段与成长序号生成，使用当前质数，逐步增加重复因子、因子种类与产品组合。费用和产品目录直接存档，读取不重新抽取。
- 数字范围 2–999999，乘法使用整数；乘积超限保留两份输入并等待，不截断、不取模。

## 共享物流站

质数 7 和数字筛选研究完成后，可研究共享物流。物流站占 2×2 格，外围 8 个端口按相邻传送带方向识别输入与输出，平行经过不连接。

每个输出端口独立设置数字，0 表示关闭。输入存入全局物流库存，任意物流站可取出指定数字，但不能直接供应机器，也不能直接支付研究。每口最多 3 个/秒，整站输入与输出合计最多 6 个/秒。选中站可查看库存、实际吞吐与缺货、堵塞、限速状态。

首次物流科技只给 2 个建造额度，不补发之前的成长奖励。之后每次扩张或完成研究加 1。额度限制同时存在的建筑数量，拆除返还已占用额度，共享库存保留。研究不能重复完成刷奖励。

## 操作

- 左键放置或选择，拖动铺带；可先建乘法机，再连接输入，也支持从输入端向外反向铺带。
- 矿点外围八格均可自动出料，只连接朝外的传送带，平行或朝内不接收；多个出口轮流共享总产量，2 为 6 个/秒、3 为 4 个/秒、其余质数为 2 个/秒，每口不超过 3 个/秒。
- 扩张与研究显示库存、需求和缺口；条件不足时仍可点击查看原因，不消耗库存。左侧底部摘要和回到研究站按钮固定显示，其余研究内容滚动查看。
- 选择仅在点击时发生，拖动抖动不改变选中设备，设备边缘有小范围点击容差。选中传送带可追踪未连接上游、具体堵塞位置和拒收数字，使用“定位阻塞”跳转；乘法机分别显示 A、B、输出方向与等待原因，异常端口以黄色标记。
- 乘法机后方输入 A、左侧输入 B、前方输出，自动乘实际输入，不指定配方。加工周期 1 秒。
- 分流器四向自动识别连接，支持合流、均分；研究后支持比例分流和各方向数字筛选。指定数字出口堵塞时等待，不绕到错误出口。
- 新带正交穿过已有直带时自动走地下，旧带保持地面。两层各一格缓存、独立运输与堵塞；交叉格不能转弯，也不能穿越设备。
- 中键拖动镜头，滚轮缩放，R 旋转，右键或 Esc 取消；1–6 切换工具，空格暂停，Ctrl+S 保存。
- 拆除普通设备会清空其缓存；交叉格支持单独拆地下通道。物流库存和研究累计不因拆除丢失。
- 新建世界需确认，可填写种子。种子限定为有符号 32 位整数，超范围会钳制，确保网页 JSON 读回一致。

## 存档

自动保存间隔 30 秒，可手动保存。桌面关闭窗口也保存；网页离开前建议点保存并等待“工厂已保存”，不要依赖浏览器强制关闭时执行回调。

当前文件为 `user://number_factory_world_v3.json`，保存布局、种子、生成区块、开放范围、科技、费用、两类库存、额度、设备设置、缓存物料、生产进度与暂停状态。关闭期间不模拟。旧有限地图存档保留在原文件中，不自动覆盖或迁移为无限世界。

无法读取的世界存档会保留原文件并禁止覆盖保存；确认新建世界后才重新允许保存。QA 界面测试不写玩家存档，实际文件测试只使用独立 QA 路径。

网页 `user://` 存入浏览器的持久存储。同一浏览器与网站来源保留进度；换端口、换域名、隐私模式或清理网站数据可能无法读取原存档。应允许网站存储；当前没有云存档和跨浏览器同步。

## 素材与许可

沿用 GPT 生成的抽象数学实验室 PNG，提示词与清单见 `assets/texture_manifest.json`。弯带使用网格校准后的 `belt_turn-v2.png`，四向分流使用 `splitter-fourway.png`，物流站暂复用枢纽贴图并实时绘制端口与“仓”标记。数字、方向与状态不烘焙进贴图。

中文使用随游戏打包的 [Noto CJK 固定字重字体](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese)，不依赖本机字体。字体采用 SIL OFL，工具栏采用 Lucide，许可分别在 `assets/fonts/OFL.txt` 和 `assets/icons/LICENSE`。导出脚本把字体、图标以及当前引擎的许可与第三方声明复制到 `build/web/licenses/`。

## 验证与边界

```powershell
.\tools\test.ps1
.\tools\test.ps1 -FullGrowth
```

普通测试覆盖运输、乘法、四向筛选、交叉、建造、贴图、成长模型、物流并发、限速与实际文件保存。`-FullGrowth` 用测试专用铺线器操作真实矿点与设备，逐项生产费用、交付研究站并支付扩张，禁止直接注入库存；它不进入正式游戏，也不替玩家规划产线。

实际验收证据与待验证项记录在 `docs/web-development.md`。网页已实际导出运行；浏览器操作验证与无界面成长测试分开记录，不能互相替代。

当前面向桌面鼠标键盘与支持 WebGL 的现代浏览器，不包含移动端、云存档、多人或无限数值。地图可持续扩张，但实际规模受内存和设备数量限制；超大世界的性能与长期数值平衡仍需专项压测。
